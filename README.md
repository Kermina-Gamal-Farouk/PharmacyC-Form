# Pharmacy Product Viewer (C# Windows Forms)

A simple desktop app built with C# and Windows Forms (.NET Framework) that displays a pharmacy product's name, price, and picture.

## Features
- Three product buttons: Shampoo, Vitamin, and Soap.
- Clicking a button fills the Product and Price fields.
- Shows the product image (hidden until a product is selected).
- Exit button closes the app.

## How to run
1. Clone or download this repository.
2. Open ex1.sln in Visual Studio.
3. Press F5 to run.
